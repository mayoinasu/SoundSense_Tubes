Petunjuk penggunaan program pendeteksi kebisingan:

Pastikan Anda sudah menginstal library yang dibutuhkan,
Untuk menginstal, bisa jalankan baris berikut pada terminal desktop:
pip install sounddevice==0.5.6 numpy==2.5.3 soundfile

Jika sudah menginstal library tersebut, silakan cek kembali isi file yang ada dalam zip.
Pastikan terdapat sebuah folder berjudul 'audio' dan di dalamnya terdapat file berjudul 'alarm.wav'.
Mohon jangan mengubah penamaan file karena akan berpengaruh pada berjalannya program.

Jika ingin menjalankan program, silakan jalankan program berjudul recorder.py

Program ini juga akan meminta akses mikrofon pengguna. Mohon izinkan program ini mengakses mikrofon agar fitur pendeteksi kebisingan kami bisa berjalan secara otomatis. Data suara yang diambil hanya digunakan untuk menghitung amplitudo suara semata, bukan merekam ataupun tersimpan dalam program.

Terima kasih! Selamat menggunakan!
